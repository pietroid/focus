# Agent Notes

This repo is curated, public content. It is written by Pietro and by his
own agents following instructions kept elsewhere. If you do not have
those instructions, treat this repo as read-only unless Pietro asks you
for a specific change.

- `notes/`: learnings, one topic per file.
- `posts/`: write-ups ready to publish elsewhere.

Plain markdown, relative links, dates as `YYYY-MM-DD`.
